# Product Overview

## Ghost Match Game (小鬼消消乐)

A web-based match-3 elimination puzzle game built with HTML5, CSS, and JavaScript. Players swap adjacent ghost icons to form lines of 3 or more identical ghosts, eliminating them to earn points. The game features intuitive UI, smooth animations, and progressive difficulty design.

### Core Gameplay
- **8x8 Grid**: Game board with clear visual boundaries and grid lines
- **5+ Ghost Types**: Different colored/styled ghost icons for variety
- **Match-3 Mechanics**: Horizontal and vertical line matching (3+ icons)
- **Swap System**: Click-based adjacent icon swapping with smooth animations
- **Gravity & Refill**: Automatic falling and top-row regeneration after eliminations
- **Combo System**: Cascading matches from single swaps with score multipliers

### User Experience Features
- **Real-time Scoring**: Live score display with elimination-based point calculation
- **Visual Feedback**: Selection highlighting, swap animations, elimination effects
- **Audio System**: Sound effects for eliminations, combos, and game events
- **Responsive Design**: Cross-device compatibility (desktop/mobile/touch)
- **Game Timer**: Session timing display
- **End Game Detection**: Automatic detection when no moves are possible

### Target Audience
Casual puzzle game enthusiasts seeking engaging match-3 gameplay with modern web technology, accessible across all devices and browsers.

### Design Philosophy
Intuitive interaction patterns with immediate visual and audio feedback, ensuring smooth gameplay flow and progressive engagement through combo mechanics.
